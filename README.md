## Getting Started
The project is split into two folders: `frontend` and `backend`.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/shimels1/Entertainment-website.git
   ```
2. **Set up the Frontend**:
   ```bash
   cd Entertainment-website/frontend
   npm install
   npm start
   ```
   Open `http://localhost:3000` in your browser.

3. **Set up the Backend**:
   ```bash
   cd Entertainment-website/backend
   npm install
   npm start
   ```
   The backend typically runs on `http://localhost:5000` (confirm port in backend configuration).

4. Ensure required APIs are configured (e.g., add API keys to a `.env` file in the backend).
